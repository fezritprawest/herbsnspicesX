1. Pengertian Bumbu vs Rempah

\
\

Rempah (Spices): Tanaman aromatik alami dari bagian tumbuhan (akar, biji, bunga, kayu) yang memberi aroma dan rasa khas pada hidangan.

\

Bumbu: Ramuan dari beberapa rempah segar/kering yang dicampur dengan bahan olahan seperti kecap, cuka, garam, tauco, atau terasi.

\
\
\ \ \
\
\ \
\

2. Fungsi Utama Dapur

\
    \
  • Memberikan rasa, warna, & aroma memikat.
    • \
  • Meningkatkan kelenjar pencernaan & selera makan.
    • \
  • Sebagai Pengawet Alami (Kunyit, Asam, Jeruk).
    • \
  • Menghilangkan bau amis pada daging & ikan.
    • \
  • Memberikan efek sensasi hangat pada tubuh.
    • \
\
\ \ \
\
\ \
\

3. Standar Mutu Keamanan

\
\

Bumbu & rempah berkualitas harus bersih, segar, tidak berserangga, bebas jamur, dan tidak berbercak putih/hitam.

\

Daya Tahan Simpan: Rempah Utuh tahan 3-5 Tahun, sedangkan rempah Bubuk tahan 1 Tahun.

\
\
\
\ \ \
\

\ Klasifikasi 6 Bagian Tumbuhan\

\ \
\ \
\ \ 1. BUNGA\ Cengkeh, Bunga Pekak, Telang, Kecombrang\
\ \
\ \ 2. BUAH & BIJI\ Lada, Ketumbar, Pala, Kemiri, Cabai, Jintan\
\ \
\ \ 3. DAUN\ Jeruk Purut, Salam, Kemangi, Peterseli, Kucai\
\ \
\ \ 4. BATANG\ Kayu Manis, Sereh, Kayu Secang\
\ \
\ \ 5. AKAR / RIMPANG\ Jahe, Kunyit, Lengkuas, Kencur\
\ \
\ \ 6. UMBI LAPIS\ Bw. Merah, Bw. Putih, Bw. Bombay, Leek\
\
\
\ \ \
\ \
\

\ 3 Bumbu Dasar Indonesia\

\
\
\ Bumbu Dasar Merah: Cabai + Bw. Merah + Bw. Putih + Garam. (Contoh: Rendang, Balado).\
\
\ Bumbu Dasar Putih: Kemiri + Bw. Merah + Bw. Putih + Garam. (Contoh: Opor, Tumisan).\
\
\ Bumbu Dasar Kuning: Kunyit + Kemiri + Bw. Merah + Bw. Putih + Garam. (Contoh: Soto, Acar).\
\
\
\ \ \
\

\ Standar Wadah Penyimpanan\

\
\
\ Opaque Glass (Sangat Baik) Kaca gelap kedap udara, melindungi dari cahaya.\
\
\ Clear Glass (Bagus) Kaca bening, harus disimpan di tempat gelap.\
\
\ Metal Tins (Kaleng) Cocok untuk rempah biji & akar kering.\
\
\ Wadah Kayu / Plastik (Hindari) Permeabel & menyerap bau sintetis.\
\
